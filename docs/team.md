# 역할 및 1차 일정

사용자가 제공한 역할표 기반. 공통 기간은 11/5~11/6이며 목표는 프로토타입·기획서 초안 및 1차 통합 검증이다.

| 담당 | 11/5 | 11/6 | 기획 |
| --- | --- | --- | --- |
| 나경 | 장소·날짜·수신자·녹음·첨부 화면 | 미리 듣기·보내기·취소·모바일 확인 | 주차안심 주 담당 |
| 유림 | DB·API 계약 | 등록·조회·음성 송수신 | ChargeGuard 통합형 주 담당 |
| 재민 | Pleos 환경·신호·권한 확인 | 신호 시험·상태 전달·mock 분리 | 아래 확인 필요 |
| 규혁 | Android 화면·테스트 음성 재생 | 서버·재생 제어·중복 방지·오디오 처리 | 말뚝 2.0 주 담당 |
| 민석 | 저장소·공통 규격·테스트 | 통합·APK 빌드·설치 확인 | 교차 검토·전체 형식 통일 |

## 확인할 불일치
재민의 기획 역할은 요약 표의 “ChargeGuard 통합형 기술 검토”와 상세의 “침수폭설 통합형 작성”이 다르다. 기획서 개수·역할을 팀에서 확정하기 전 임의 통합하지 않는다.

## 통합 책임
- 웹 ↔ 서버: 나경·유림.
- 서버 ↔ 차량 앱: 유림·규혁.
- 차량 상태 ↔ 재생 조건: 재민·규혁·민석.
- APK 의존성·권한·설치 환경: 재민·규혁·민석.
- 전체 통합: 민석 중심, 전원 참여.

프로토타입 완료와 최종 완료를 구분한다. 최종 목표는 음성 등록 → 차량 수신·재생과 APK·GitHub·시연 자료 준비다.
