## 검증

PowerShell 7과 Python 표준 라이브러리 기반 임시 모의 서버에서 10개 시나리오를 검사했다.
정상 응답, 서버 500, 잘못된 JSON, 숫자 ID, 조회 ID 누락, 잘못된 목록,
빈 음성, HTML 음성 응답, 리다이렉트, 서버 연결 실패를 확인했다.
토큰 분리, multipart 필드·바이너리 전달, 다운로드 파일 내용과 비밀값 미출력도 확인했다.
실제 서버·Pleos 검증은 미실행이다. Windows PowerShell 5.1 호환 API를 사용했으나 해당 런타임은 미검증이다.

## 미결 사항

인증 방식, 지원 음성 형식과 제한 크기, 실제 서버 주소 및 목록 조회 조건은 팀 합의가 필요하다.
실행마다 서버 메시지가 생기며 자동 삭제 API는 계약에 없어 구현하지 않았다.
