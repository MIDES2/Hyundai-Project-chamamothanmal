# 보안과 데이터 처리

아래는 설계와 검증 기준입니다. 인증 방식, 저장 기간 및 삭제 절차는 구현 전에 팀에서 확정합니다.

- 서버에서 요청자의 메시지 접근 권한을 확인합니다. 목록·상세·파일 다운로드·재생 결과 갱신에 같은 기준을 적용합니다.
- 파일 크기와 실제 형식을 검증하고, 서버에서 저장 이름을 정합니다. 음성을 공개 경로에 두지 않습니다.
- 수신자의 이동 경로는 수집하지 않는 방향으로 설계합니다. 발신자에게 정확한 도착·주차 시각을 노출하지 않습니다.
- 테스트는 가상 수신자와 샘플 음성으로 진행합니다. 토큰·음성·정밀 좌표는 Git과 테스트 로그에 남기지 않습니다.

유림은 서버 구현과 API 계약을 담당하고 민석은 보안 테스트와 통합 검증을 조율합니다. [통합 검증](../tests/integration/README.md)
