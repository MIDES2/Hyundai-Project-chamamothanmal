# 1차 통합 검증

아래 항목은 전부 미실행이다. 실행 시 날짜·커밋·환경·실제/mock·기대/실제 결과·담당·오류 링크를 기록한다.

| ID | 시나리오 | 확인 기준 |
| --- | --- | --- |
| INT-01 | 웹 음성 등록 → 차량 조회·수신 → 재생 | 같은 메시지 ID로 흐름 확인 |
| INT-02 | 업로드 실패·파일 형식/크기 오류 | 오류 안내·불완전 등록 처리 |
| INT-03 | 재생 보류·상태 미확인·주행 상태 | 합의한 재생 조건 준수 |
| INT-04 | 중복 요청·중복 이벤트·앱 재시작 | 중복 재생 방지 |
| INT-05 | 네트워크 단절·다운로드 실패 | 실패 기록·재시도 정책 준수 |
| INT-06 | 수동 재생·건너뛰기·오디오 포커스 | 제어와 중단/복구 정책 확인 |
| INT-07 | 권한 없는 메시지·음성 접근 | 접근 거부 |
| INT-08 | APK 빌드·설치·실행 | 환경·권한·SDK 버전·결과 기록 |

## 제출 체크리스트
- [ ] 통합 결과 및 남은 오류 목록
- [ ] SDK 실제 지원과 mock 결과 구분
- [ ] APK 또는 빌드 차단 원인·후속 작업
- [ ] 각 앱 실행 방법과 환경 설정
- [ ] 기획서 역할 불일치 해소 및 통합 검토본
- [ ] 시연 영상 구성안·최종 제출물
