## 초기 v0.1 API 통합 검사 실행 도구

현재 서버 규격과 다르므로 아래 도구를 최신 앱 연동에 사용하지 않는다.
최신 서버 검사는 `services/api/scripts/smoke-test.ps1`에서 실행한다.
[서버 팀 연동 안내](../../services/api/TEAM_INTEGRATION.md)를 따른다.

`voice-message-smoke.ps1`은 현재 v0.1 계약을 기준으로 음성 등록, 수신자 목록 조회,
음성 다운로드를 순서대로 검사한다. 등록할 때마다 서버에 테스트 메시지 한 건이 생긴다.
샘플 데이터와 팀 테스트 서버를 사용하고, 남은 메시지는 서버가 제공하는 삭제 절차로 정리한다.

### 실행

Windows PowerShell 5.1 또는 PowerShell 7에서 저장소 루트 기준으로 실행한다.
실제 검증은 PowerShell 7에서 수행했다. 서버가 실행된 상태여야 한다.
아래 주소는 예시이며 `BaseUrl`은 `/api/v1/messages` 앞의 서버 루트 주소다.

```powershell
.\tests\integration\voice-message-smoke.ps1 -BaseUrl 'http://localhost:8000' -AudioPath 'D:\test-audio\sample.wav' -AudioContentType 'audio/wav' -RecipientId 'test-user-a' -PlaceName '테스트 장소' -Latitude 37.5 -Longitude 127.0 -ScheduledDate '2026-11-10'
```

- `AudioPath`는 PC에 있는 테스트 음성의 실제 경로로 바꾼다.
- `AudioContentType`은 샘플의 실제 MIME 형식으로 지정한다. WAV는 `audio/wav`,
  MP3는 `audio/mpeg`가 예시이며 서버가 지원하는 형식은 팀에서 합의한다.
- `ScheduledDate`는 테스트할 유효한 날짜를 지정한다.
- 인증이 Bearer 토큰이면 실행할 터미널의 `MALTTUK_SENDER_TOKEN`과
  `MALTTUK_RECIPIENT_TOKEN` 환경변수에 각각 발신자·수신자 테스트 토큰을 준비한다.
  다른 변수 이름은 `-SenderTokenEnv`, `-RecipientTokenEnv`로 지정한다.
- 토큰 변수가 비어 있으면 해당 요청은 인증 헤더 없이 전송된다.
  이는 접근권한 검증을 통과했다는 의미가 아니다.
- 이 도구는 `.env`를 자동으로 읽지 않는다. 인증 방식이 바뀌면 요청 헤더도 맞춰 수정한다.
- `-TimeoutSeconds`의 기본값은 HTTP 요청당 30초다.
- 클라이언트의 샘플·응답 크기는 각각 최대 32 MiB로 제한한다. 서버의 업로드 제한은 별도 합의한다.

### 출력과 판정

각 단계에 `[PASS]`가 표시되고 종료 코드가 `0`이면 API 흐름 검사가 통과한 것이다.
실패하면 `[FAIL]` 뒤에 단계와 마지막 HTTP 상태를 표시하고 종료 코드 `1`을 반환한다.
상태 `0`은 HTTP 응답을 받기 전의 실패를 뜻한다. 응답 본문과 토큰은 출력하지 않는다.

다운로드는 실행마다 다른 임시 폴더에 `downloaded-audio.bin`으로 저장한다.
필요한 경우 결과 파일의 이름을 실제 형식으로 바꿔 수동 재생한다.
검사가 끝난 테스트 다운로드 파일은 사용자가 정리한다.

이 도구는 현재 목록 응답의 `items` 배열에서 메시지를 찾는다.
페이지네이션·검색 조건이 추가되면 계약에 맞춰 확장한다.
리다이렉트는 따라가지 않으며, 실패한 등록 요청을 자동 재시도하지 않는다.

이 검사는 API를 직접 호출한다. 모바일 화면 조작, 음성의 실제 디코딩·동일성,
차량 스피커 재생, Pleos 이벤트, 중복 재생 방지 및 INT-07 인가 검사는 별도로 수행한다.
서버의 실제 동작은 아직 미검증이다.

### 도구 자체 검증 기록

2026-11-10 로컬 모의 HTTP 서버와 PowerShell 7에서 아래를 확인했다.

- 정상 multipart 등록·수신자 조회·다운로드와 토큰 분리
- 서버 500, 잘못된 JSON, 숫자 messageId, 목록에서 ID 누락, 잘못된 목록 구조 거부
- 빈 음성, HTML 다운로드, HTTP 리다이렉트 거부
- 연결할 수 없는 서버에서 실패 종료
- 토큰과 서버 오류 본문이 출력되지 않음

모의 서버 검증 결과는 실제 말뚝 서버·차량 통합 결과와 구분한다.
