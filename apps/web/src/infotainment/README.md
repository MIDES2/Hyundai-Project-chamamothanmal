# Infotainment — 차량 앱

차량용 브라우저 UI 코드는 이 폴더에 있습니다. Infotainment는 인포테인먼트의 영어 표기입니다.

- `pages/`: 첫 인사·이동/도착·듣기/포기·재생·반응·목록·보관함·설정 화면
- `VehicleApp.jsx`: 차량 화면 전환·타이머·자동 보관 상태
- `main.jsx`: 차량 진입점
- `vehicle.css`: 차량 스타일
- `components/`, `StatusBar.jsx`, `DockIcon.jsx`, `RetentionPicker.jsx`: 차량 공통 UI
- `archive.js`: 보관 기한과 로컬 보관함

두 앱이 함께 쓰는 아이콘과 이미지는 `../shared/`에 있습니다. Android/Pleos 실차 코드는 저장소의 `apps/vehicle`에서 별도 개발합니다.
