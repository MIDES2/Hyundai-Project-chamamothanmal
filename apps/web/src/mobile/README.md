# Mobile — 휴대폰 앱

휴대폰 앱 코드는 이 폴더에 있습니다.

- `pages/`: 로그인·회원가입·홈·꽂아둔말·보관함·MY 등 화면별 코드
- `components/`: 달력·플레이어·버튼·메시지 카드 등 휴대폰 공통 UI
- `App.jsx`: 휴대폰 화면 전환과 상태
- `main.jsx`: 휴대폰 진입점
- `styles.css`: 휴대폰 스타일
- `maps/`, `PlacePicker.jsx`, `RecipientPicker.jsx`, `Notifications.jsx`, `accounts.js`: 지도·대상 선택·알림·데모 계정

두 앱이 함께 쓰는 아이콘과 이미지는 `../shared/`에 있습니다.
