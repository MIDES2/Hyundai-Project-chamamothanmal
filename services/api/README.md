# 백엔드 및 DB

유림 담당. Java·Kotlin 기반으로 메시지 등록·조회, 음성 업로드·다운로드와 재생 결과 갱신을 설계합니다.

서버 프레임워크, DB, JDK·Gradle 버전과 실행 명령을 팀에서 확정합니다. 인증·메시지 단위 인가와 파일 제한은 민석과 협의하고, API 요청·응답 예시는 연동 계약에 남깁니다. 루트 환경변수 예시는 서버 설정 제안입니다.

## 메시지 접근권한 코드

[security/README.md](security/README.md)의 Java 수신자 권한 검사와 테스트를 준비했다.
서버 인증에서 확인한 사용자 ID와 저장소에서 조회한 수신자 ID를 전달해 사용한다.
실제 API 연결과 INT-07은 서버 프로젝트 구성 후 검증한다.
